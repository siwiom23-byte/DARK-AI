# DARK AI — مشروع Android أولي

هذه نسخة أولية لواجهة تطبيق Android باسم DARK AI، مبنية باستخدام Kotlin وJetpack Compose.

## ما الموجود حالياً؟
- واجهة دردشة عربية داكنة.
- رسائل تجريبية داخل التطبيق.
- قائمة شكلية لاختيار النموذج.
- أزرار مبدئية للمرفقات والصور والصوت.

## ما الذي لم يُربط بعد؟
هذه ليست خدمة ذكاء اصطناعي مكتملة بعد. يلزم تطوير وربط:
- خادم وسيط (Backend) يتصل بمزودي نماذج الذكاء الاصطناعي.
- مفاتيح API محفوظة على الخادم، وليس داخل التطبيق.
- تسجيل الحسابات وحفظ المحادثات.
- رفع الصور وتحليلها وتوليد الصور.
- تحويل الكلام إلى نص والنص إلى صوت.
- حدود استخدام واشتراكات اختيارية.

## البناء
1. افتح المشروع في Android Studio على جهاز كمبيوتر.
2. انتظر مزامنة Gradle.
3. اختر Build > Build APK(s).
4. سيظهر ملف APK التجريبي داخل `app/build/outputs/apk/debug/`.

يتطلب البناء اتصالاً بالإنترنت لتنزيل أدوات Gradle ومكتبات Android.

## تنبيه أمان
لا تضع مفاتيح API السرية داخل كود Android أو ملف APK. استخدم خادماً وسيطاً، مع مصادقة وحدود استخدام.
